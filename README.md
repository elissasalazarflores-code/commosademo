# Cine Commosa × TaquillApp — Demo

Demo de una sola página del beneficio corporativo de cine para colaboradores Commosa, operado por TaquillApp para Empresas.

**Uso offline:** abre `index.html` con doble clic en cualquier navegador. No requiere internet: estilos, logo y lógica están dentro del archivo.

Incluye: hero con el mensaje “El mejor precio para ir al cine, siempre.” y “Más de 50% de descuento”, cómo funciona, catálogo Cinépolis/Cinemex/Combos con filtros, compra simulada (carrito → validación de colaborador → pago con nómina o tarjeta → folios generados), calculadora de ahorro, instrucciones de canje y preguntas frecuentes.

Todos los pagos, validaciones y folios son simulados. Los precios se basan en el catálogo de TaquillApp; el “precio en taquilla” es una referencia ilustrativa.
